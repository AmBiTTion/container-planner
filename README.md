# 柜里 · 本地 3D 装柜规划

程序安装在 `D:\ContainerPlanner`。双击 `启动柜里.cmd`（或 `Start-ContainerPlanner.cmd`）启动，会保留一个可见控制台并打开浏览器：http://127.0.0.1:4173 。完成后可关闭控制台，或双击 `关闭柜里.cmd`（`Stop-ContainerPlanner.cmd`）停止服务。关闭网页不会删除方案。

启动入口直接运行本地 `runtime\node.exe` 和可查看的 `launcher.mjs`，不使用 PowerShell 启动脚本、执行策略绕过、开机自启、计划任务或白名单设置。2026-09-07 火绒对开发时的 `start.ps1` 报警后，已移除 PowerShell 启动 / 停止脚本。

核心功能可离线使用，不需要账号或云服务。Node 运行时、3D 库和构建产物随项目保存在 D 盘。浏览器本身的缓存和下载位置遵循浏览器设置。

## 建议先试这三条流程

1. **纸箱散装**：右上「示例方案」→「纸箱散装」→比较候选方案→单击货物→锁定或修改坐标→再次自动计算。
2. **编织袋压缩码托**：「示例方案」→「编织袋」→编辑货物→调整高度压缩和有效长宽→重新计算码托→「保存整托，准备入柜」→在整托库点击「放入」。
3. **整托与散件混装**：先放入整托并锁定→添加纸箱或软包→选择数量优先或空间优先→自动填充→查看「检查」与「未装清单」。

自动计算会保留锁定货物，重新排列未锁定的部分。修改尺寸后，旧摆放可能产生碰撞或悬空，系统会重新提示，需要重新计算或手动修正。

## 数据与计算口径

- 坐标为 mm：X 沿柜长（0 是柜内深处，最大值是柜门），Y 沿柜宽，Z 向上。摆放坐标是旋转后水平包络的左下角和底部高度。
- 货物尺寸应为装满后的包装外形，不能用空袋平铺尺寸代替。袋子压扁可能向两侧鼓起，有效长宽需据实调整。
- 柜内载货重量包括货物和已装托盘；含柜总重再加柜体自重。码托载货重量不含工作台托盘；含托总重另加自重。
- 整托与散件共用货物库存。整托库的可用托数只是组合上限，不是额外的货物库存。
- 托盘工作区是一个码托方案草稿，不重复扣减柜内库存。保存整托后，实例才进入装柜计算。
- 利用率为有效包装外形体积占比；整托按内部货物加底座外形体积统计。外形体积含包装空隙，底座按包络估算，并非材料实体体积。剩余体积不表示同体积物品一定放得下。
- 重心按已装货物与整托质量计算，不含柜体。码托区重心不含工作台托盘，Z 从底座上表面起算。
- “要求全部装完”作为优先目标；未满足时在检查与报告中明确列出，不强行制造不合法摆法。

## 目前明确的边界

- 袋子采用可调包络和袋状外观，不模拟真实柔性材料受力变形；压缩尺寸由用户确定。
- 自动朝向为平放、水平 0° / 90°；手动支持任意水平角度。尚未提供侧躺、倒置等三轴姿态搜索。
- 算法为有时间预算的启发式搜索，不承诺全局最优。快速常规搜索 2 组，深度 4 组；单一自动规格、没有锁定货物时，额外比较水平 0°/90° 横竖混排行组合。常规搜索预算约 12 / 40 秒，实际另有混排比较、最终校验与绘制时间。
- 自动计算与项目上限统一为 5000 个装载单元、200 种规格；单次手动阵列仍最多 1500 个，避免误操作生成过多。右侧明细列表显示前 250 项，导出含完整数据。达到时间预算、单元上限或候选点用尽会分别提示，不当作“空间已满”的证明。
- 整托整体外形保守占用空间，内部孔隙不自动填入散件。解散后可单独调整货物。
- 支撑与载荷采用接触面积分摊的静态估算，不验证摩擦、倾覆、动态振动、地板局部压力或包装真实承压能力。
- 柜门基础检查按装载单元当前宽高；另有可选直线几何装卸路径检查，必须填写设备、通道和柜外空间。不能替代真实叉车通行、转弯及安全验收。
- 商超名称提供分类入口，未内置未经核实的官方规则。模板填写来源和版本后可由用户标记核实。标签朝向是人工核对项，混托检查按不同货物规格区分。
- HTML 报告可在浏览器直接打印保存 PDF；没有上传服务器或第三方转换服务。

## 2026-09-09：袋子混排、实时预览与收拢工具

- **规格实时预览**：左侧「自定义货物规格」或规格卡片铅笔。拖动模型旋转、滚轮缩放；灰线是原始包络，彩色外框是有效计算包络。修改尺寸或高度压缩立即更新，关闭/取消不保存更改。袋形不是材料受力模拟，压扁后的长宽需人工测量填写；纸箱使用原始尺寸。
- **场景工具**：三维场景左侧竖栏最上方的调节图标，点击展开/收起框选、二维编辑、临时重叠和柜门控制。选定框选或二维模式后自动收起；正在手动放置时仍显示简短坐标与可放状态。
- **空余与未装原因**：右侧「配载方案」底部查看说明，或点场景左侧竖栏最下方的空余空间图标。三维线框/二维投影与编号说明可随时隐藏。按完整实际布局而非当前可见层计算；最多展示 12 个空区，复杂布局可能只显示部分结果。任意角度货物用保守 AABB 排除占用区域；这些矩形余隙不是完整可用空间搜索，“尺寸可容纳”仍需通过支撑、间距、承重等校验。
- **实际规格回归**：40HC 12032×2352×2698 mm，袋子有效尺寸 500×400×152 mm、10.8 kg，库存 2520，允许水平转向，最高第 50 层、上方负载 400 kg，零间距/预留且无锁定货物。新候选装 138 件/层 × 17 层 = 2346 件、25336.8 kg。主要余隙为顶部 114 mm、侧边 52 mm、柜尾 32 mm。2520 件总计 27216 kg，超过当前 26500 kg 载重；单按重量最多 2453 件，不代表几何上一定能装到该数。
- 原有锁定货物不会被自动重排。希望从头比较混排时，请先保存方案，再「解锁全部」后计算；可通过撤销恢复。
- **集装箱皮肤**：左侧「装载设置 → 集装箱皮肤」可切换经典海运绿、远洋蓝、货柜红、冷藏白、石墨灰、沙漠黄或自定义主色。柜壁、地板、门板、加强筋、门框和五金会协调变化，并随方案和导出截图保存。皮肤是视觉属性，不参与尺寸、碰撞、重量与配载计算。

- **拍照展示模式**：顶部「拍照展示」隐藏编辑界面，保留立体/俯视/柜门/柜内视角、墙体、背景和自动旋转控制，可下载提高清晰度的 PNG，不修改方案。

## 保存、备份与恢复

正常工作会自动保存到 `D:\ContainerPlanner\data\<项目编号>.json`，同目录的 `.backup.json` 保留上一版。方案库不显示备份文件。需要恢复时，可通过「方案库 → 导入项目」选择备份，恢复为新方案，不覆盖当前方案。

修改后看到“已保存到本机”再关闭。重要方案建议再导出完整 JSON。导出默认进入浏览器的下载目录。

命名历史版本与附件存放在 `data\records\<项目编号>`。JSON 导出保留附件引用，不包含附件文件；完整迁移请复制整个 `data` 文件夹。现场记录 HTML 会内嵌已保存照片，可单独发给同事。不要单独删掉原项目的附件目录，因为副本可能仍引用它。

## 手动编辑与作业工具

### 场景内手动编辑

- 工具条「框选」「全选可见」「选择本层」。Ctrl / Shift 单击可多选；三维框选按投影中心穿透选择当前显示范围内的货物。
- 右侧「选中 N 件」提供整组移动、旋转、复制、锁定/解锁、删除；整组一次校验、一次撤销。移动或旋转时遇到锁定件会拒绝整组操作。
- 「对齐 / 间距」：组内起始边/中心/末端对齐，整组在工作区居中或贴边，指定净间距连续排列，在现有跨度内等距排列。改变布局后仍检查支撑和碰撞。
- 「复制整层」：选择同一底部 Z 高度的源层，填写新增层数与层高，可让相邻层交替转 90°。库存、层数、底部支撑与承重仍生效，不自动缩小货物适应托盘。
- 「二维俯视」「二维侧视」可用鼠标拖动；空白处拖框、Ctrl 多选、右键平移、滚轮缩放。俯视调整 X/Y，侧视调整 X/Z。精确值可在右侧改坐标或用整组位移输入。
- 「仅看当前层」配合底部层数选择器隔离编辑层；支撑层级不一定等于同一绝对高度。新增货物在二维俯视可看预览并点击落位，侧视新增请使用指定坐标。
- 碰撞箱与临时重叠沿用原规则：临时重叠仅用于调整，仍标记为草稿；边界、重量、支撑、间距及柜门碰撞不会被绕过。
- 柜门可以点击单扇开关或用按钮开关双门；有扫掠碰撞检测。浏览视角下按住鼠标中键上下拖动可推进/后退，轮滚动继续缩放。

### 整托内容编辑

在集装箱中选中一托，右侧「编辑托内货物」进入码托区。这里可以手动点放、拖动、多选、复制层或自动计算。完成后选择：

- 「仅应用这一托」：产生单托专属规格，其他同规格托盘不改变。
- 「应用同规格全部」：更新原规格，所有引用它的托盘同步更新。
- 「取消编辑」：不改柜内整托；恢复进入前的码托工作区。

应用前重新校验柜内库存、碰撞、支撑、限高和载重。失败时仍留在编辑状态，原整托不部分更新。编辑会话随项目保存，重开后仍可完成或取消。

### 顶部「作业工具」

1. **现场余量 / 区域重量**：门口、顶部、首端绑扎空间、每侧余量、水平货间距。区域重量按单元外包络均匀分摊估算，前半是柜内深处、后半是靠门；低/高 Y 各半区单独显示。用户限值 0 表示不设上限，不是轴荷/结构验算。
2. **袋子容差与装量比较**：人工设置理想有效尺寸及三方向正容差，保守外形 = 理想外形 + 容差。质量不变。可重新计算理想/保守装量并另存打开，不覆盖原方案；比較不保留原锁定摆放。
3. **Excel 批量导入**：XLSX / UTF-8 CSV，选工作表和 mm/cm/m、kg/g 单位，逐行预览后一次性新增规格。旧 XLS 请另存 XLSX。公式仅读已保存计算值，不自动运行公式。模板下载在导入对话框内。每文件最多 6MB，解压目录声明总量最多 50MB，最多 5000 数据行；项目仍最多 200 规格。
4. **多柜分配 / 运费比较**：从可自动装载的全部库存重新分配，按柜扣减货物和托内库存。可分别比较三个标准柜型，或输入混合柜型顺序（最后一个柜型重复）。每组最多 20 柜、约 90 秒预算；每柜最多 5000 个自动装载单元。未填运费显示未估价；结果明确显示剩余库存。结果随方案保存，「查看已保存的分柜结果」可重开；输入变化时要求重新计算。每柜可另存打开检查。
5. **版本历史**：给当前方案命名留存、与当前比较、恢复。恢复前自动新建一份当前状态备份。对比包括件数、重量、利用率、错误数、布局增删改与配置变化；不依赖 35 次撤销历史。
6. **现场装柜核对**：整托按托数、散货按件数填实装；空白为未核对，0 为确认未装。填写柜号、封条号、核对人、差异原因和照片。先保存再确认完成，缺数量/差异说明时拒绝确认；方案变更会标记旧记录过期。记录可导出内嵌照片的独立 HTML。每张照片最多 6MB，每记录最多 30 张。
7. **几何装卸路径**：固定当前朝向，沿 X 方向直进/直退，在目标处升降；需明确设备尺寸、额外包络、抬升量、通道宽和柜外进退空间。设备三维填 0 表示只检查货物。柜门假定完全打开。遇阻停止，后续步骤标为未验证，可定位对应货物。不模拟转弯、叉齿、地坪承载、倾覆与驾驶安全。

客户规则的来源附件、生效/有效至日期，在「客户规则 → 编辑」内。PDF、图片、XLSX、DOCX、TXT/CSV 每文件最多 6MB，每条规则最多 10 个附件；只做本地留档，不把文件内容自动认定为官方规则。过期或未生效的已应用规则会提示复核。

中英文装载 HTML 报告同时包含已启用的余量、区域重量、袋子容差和客户来源有效期。客户附件本体不嵌入装载报告，仅列名称与校验值；现场照片由专用现场记录 HTML 内嵌。

不要删除 `data` 文件夹。`work\qa` 是独立测试产物，不参与实际方案库。
